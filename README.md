# Борт24 — лендинг

Статичная версия лендинга «Борт24 — программа для перевозчиков».

- `index.html` — страница (разметка и логика лендинга).
- `dc-lite.js` — небольшой рендерер шаблона страницы, без зависимостей.
- `img/route.jpg` — фото для блока заявки.

Публикуется через GitHub Pages из ветки `main`, папка `/` (root).

До запуска: форма заявки пока никуда не отправляет данные; контакты, «Войти», страница статуса и Telegram — заглушки.
